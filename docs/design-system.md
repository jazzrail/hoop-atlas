This one caused our original confusion.

**The design system isn't really about why the site looks a certain way.**

It's about:

**"What reusable things have we built?"**

For example:

# Hoop Atlas Design System

## Components

### Court Card

A reusable component displaying:

- court image
- court name
- location
- court type
- short description
- link

### Search

Contains:

- search input
- search icon
- clear button

### Button

Variants:

- Primary
- Secondary
- Ghost

### Badge

Used for:

- court type
- surface condition
- lighting

## Layouts

### Court Grid

Used to display multiple court cards.

### Court Detail

Used to display information about an individual court.
