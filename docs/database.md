# Hoop Atlas Database

## Status

Database design is currently being developed.

## Main Table

`courts`

## Current Fields

| Field | Purpose |
|---|---|
| `id` | Unique court ID |
| `name` | Court / site name |
| `city` | City or town |
| `postcode` | Postcode |
| `county` | County |
| `surface` | Surface type |
| `surface_condition` | Surface condition |
| `hoops` | Number of hoops |

## Notes

The database schema is still being developed.
