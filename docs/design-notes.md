# Hoop Atlas Design Notes

## 2026-08-24

### Landing Page

We decided to simplify the landing page.

Instead of two large images, use one image with:

- bold introductory text
- search
- a small stylised graphic or animation ot thought cloud idea

The overall feel should be young, urban and slightly gritty.

The courts themselves should remain the focus.

## Inspiration

- brutalistwebsites.com

## Words

- Find Hoops
- Play Ball

## Design Decisions

### Page Title

Reduce the size of the main title so that the courts remain visually prominent.

### Orange Accent

Keep orange as the main accent colour throughout the site.

Use it consistently for:

- buttons
- links
- search focus
- badges
