# Hoop Atlas Style Guide

## Design Principles

- Mobile first.
- Clear typography over decoration.
- Plenty of space.
- Photos should tell the story.
- One primary action per screen.
- Consistency beats cleverness.

## Colours

- Background: `#0f172a`
- Cards: `#1e293b`
- Text: `#e2e8f0`
- Accent: `#f97316`

## Naming Conventions

| Thing | Convention | Example |
|---|---|---|
| Folders | lowercase + hyphens | `site-notes` |
| Files | lowercase + hyphens | `court-card.php` |
| CSS classes | lowercase + hyphens | `.court-card` |
| JavaScript variables | camelCase | `courtName` |
| PHP variables | camelCase | `$courtName` |
| Database columns | snake_case | `court_name` |
| Database tables | plural | `courts` |
